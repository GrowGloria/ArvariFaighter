# Битва Героев — 2D-файтинг по миру ДнД

C# / .NET 9 / MonoGame (DesktopGL). Пиксельная графика: виртуальный экран 480×270, бойцы в кадрах 64×64.

Главная идея: **персонаж — это данные, а не код**. Движок один и тот же для всех, а боец описан
JSON-файлами и спрайтшитом. Чтобы добавить персонажа, достаточно создать папку, код менять не нужно.

## Запуск

```bash
dotnet run --project src/DndFighter
```

Самопроверка без окна (грузит весь контент и прогоняет скриптованные бои):

```bash
dotnet run --project src/DndFighter -- --selftest
```

Перегенерировать спрайты-заглушки:

```bash
dotnet run --project tools/SpriteGen
```

## Управление

| | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | W A S D | Стрелки |
| Лёгкая / средняя / тяжёлая (L / M / H) | J / K / L | Num1 / Num2 / Num3 |
| Бросок | J + K | Num1 + Num2 |

Esc — пауза, F11 — полный экран, F2 — показать хитбоксы. Раскладка меняется в `Content/controls.json`.

**Нумпад-нотация** (как в большинстве файтингов), считается относительно того, куда смотрит боец:

```
7 8 9      4 — назад (блок), 6 — вперёд
4 5 6      2 — присед, 1 — присед-блок
1 2 3      236 — вниз, вниз-вперёд, вперёд («четверть круга»)
```

**Тренировка:** F1 — режим манекена (стоит / сидит / прыгает / блок всего / блок случайно),
F3 — сброс позиций, F4 — бесконечные ресурсы, **F5 — перечитать JSON и спрайты не выходя из боя**.
Внизу экрана показывается фреймдата приёма и преимущество по кадрам после попадания или блока.

## Персонажи

**Торин, паладин** — ближний бой, сильные удары, ячейки копятся по ходу боя.

| Команда | Приём |
|---|---|
| 236L | Натиск щитом |
| 236H | Божественная кара (1 ячейка) |
| 214M | Возложение рук, лечение (1 ячейка) |
| 623H | Восходящий удар (неуязвим на старте) |

**Элара, волшебница** — дальний бой («зонер»): хрупкая, медленно идёт вперёд, быстро отступает,
у посоха самые длинные удары. Держит соперника на расстоянии.
Ячейки восстанавливаются сами, плюс есть «Магическое восстановление».

| Команда | Приём |
|---|---|
| 236L | Огненный снаряд: медленный заговор, бесплатно |
| 236M | Луч холода: быстрый заговор, бесплатно |
| j.236L | Огонь с высоты: из прыжка вниз-вперёд |
| 236H | Волшебная стрела, 3 дротика (1 ячейка) |
| 214H | Облако кинжалов: висящая ловушка, бьёт несколько раз (1 ячейка) |
| 214L / 214M | Туманный шаг назад / вперёд, неуязвимый телепорт (1 ячейка) |
| 623H | Волна грома: отбросить соперника вплотную (1 ячейка) |

Заговоры делят лимит: на экране может быть только один огненный снаряд или луч холода.

## Структура

```
src/DndFighter/
  Content/                 ← ВСЁ, что редактирует дизайнер
    characters/<id>/       ← один персонаж = одна папка
      character.json       ← статы, спрайты, анимации, хёртбоксы, ресурсы
      moves.json           ← список приёмов (можно также папку moves/*.json)
      sprites.png, fx.png
    stages/<id>/stage.json ← арены
    controls.json          ← клавиши
  Combat/                  ← ядро боя
    Fighter.cs             ← машина состояний бойца
    FightWorld.cs          ← столкновения, попадания, блок, броски, снаряды
    Effects/               ← библиотека эффектов для приёмов (расширяемая)
    Behaviors/             ← уникальные C#-механики персонажей (расширяемые)
  Input/                   ← буфер ввода, распознавание 236/623/…, клавиатура
  Data/                    ← классы, в которые читается JSON, и загрузчик
  Scenes/                  ← титул, выбор бойцов, бой (раунды, тренировка)
  Rendering/               ← отрисовка мира и HUD
  Training/                ← манекен
tools/SpriteGen/           ← генератор пиксельных заглушек
```

## Как добавить нового персонажа

1. Скопируй папку `Content/characters/paladin` в `Content/characters/<новый_id>`.
2. В `character.json` поменяй `id`, `name`, `title`, статы и ресурсы.
3. Нарисуй `sprites.png` в той же сетке: кадры 64×64, 8 столбцов, строки по порядку из `animations`.
   Точка `origin` (32, 60) — это место между ступнями, где персонаж стоит на полу.
   Пока арта нет, можно оставить спрайты паладина или добавить своего героя в `tools/SpriteGen` (поменять цвета в `Look`).
4. Опиши приёмы в `moves.json`.
5. Запусти игру: персонаж сам появится на экране выбора. Ошибки в JSON показываются красным на титульном экране.
6. Отлаживай в тренировке: F2 показывает хитбоксы, F5 перечитывает файлы на лету.

### character.json

| Поле | Что это |
|---|---|
| `stats` | `health`, `walkSpeed`, `backWalkSpeed`, `jumpVelocity`, `jumpSpeedX`, `gravity`, `preJumpFrames`, `landingFrames` |
| `resources` | классовые ресурсы: `id`, `name`, `max`, `start`, `regenPerSecond`, `gainOnHit`, `gainOnBlocked`, `gainOnDamaged`, `display` (`pips` — кружки или `bar` — полоса), `color` |
| `sheets` | спрайтшиты: `file`, `frameWidth`, `frameHeight`, `originX`, `originY` |
| `animations` | `sheet` (по умолчанию `body`), `row`, `frames`, `frameTime` (тиков на кадр; 0 — растянуть), `loop`, `hitFrame` |
| `hurtboxes` | уязвимые зоны для стоек `stand`, `crouch`, `air`: список `{x, y, w, h}` |
| `pushbox` | «тело», сквозь которое нельзя пройти |
| `behavior` | необязательно: имя C#-поведения (см. ниже) |

Обязательные анимации: `idle walk crouch jump hit block crouch_block air_hit knockdown getup victory`.

Координаты боксов считаются от ступней: `x` — вперёд по взгляду, `y` — вниз (голова примерно на −50).

`hitFrame` у анимации приёма — это индекс «ударного» кадра. Кадры до него растягиваются на startup,
сам он показывается во время active, остальные — во время recovery. Меняешь фреймдату, и анимация подстраивается сама.

### Приём (moves.json)

```jsonc
{
  "id": "smite", "name": "Божественная кара",
  "input": "236H",          // 5L, 2M, 6H, j.H, 236L, 214M, 623H, 41236H, LM (бросок)…
  "type": "special",        // normal | special | super | throw
  "animation": "smite",     // по умолчанию = id
  "startup": 14, "active": 4, "recovery": 24,
  "cost": { "slots": 1 },
  "hitboxes": [ { "x": 6, "y": -56, "w": 40, "h": 50 } ],   // start/end/group — необязательно
  "hit": {
    "damage": 170, "chip": 25,            // урон и урон по блоку
    "hitstun": 24, "blockstun": 16, "hitstop": 14, "pushback": 5,
    "height": "mid",                      // mid | low (блок сидя) | overhead (блок стоя)
    "knockdown": true, "launch": { "x": 3, "y": -5 }
  },
  "cancels": [ "special" ],               // id приёмов или категории normal/special/super
  "effects": [ { "type": "impulse", "frame": 10, "x": 4 } ]
}
```

Многоударный приём: несколько хитбоксов с разными `group` и своими `start`/`end`.
Бросок: `"input": "LM"` плюс `throwRange`. Урон и подброс берутся из `hit`.

### Библиотека эффектов

| type | Параметры | Пример использования |
|---|---|---|
| `projectile` | `id`, `animation`, `offsetX/Y`, `speedX/Y`, `gravity`, `box`, `hit`, `hits`, `lifetime`, `limit` | огненный снаряд, стрелы |
| `impulse` | `x`, `y`, `set` | рывки, прыжковые удары |
| `teleport` | `x` или `behindOpponent` + `distance` | туманный шаг |
| `heal` | `amount` | лечение |
| `resource` | `id`, `amount` | набрать ярость |
| `invulnerable` | `frames` | неуязвимые реверсалы |
| `popup` | `text`, `color` | надписи «КАРА!» |

Каждый эффект срабатывает на кадре `frame` приёма.

## Расширение на C#

**Новый эффект** — один класс, регистрировать нигде не нужно:

```csharp
[Effect("slow")]
public sealed class SlowEffect : MoveEffect<SlowEffect.Params>
{
    public sealed class Params { public int Frames { get; set; } = 60; }

    protected override void Execute(Fighter self, Params p, FightWorld world)
    {
        // ...
    }
}
```

После этого в JSON сразу доступно `{ "type": "slow", "frame": 5, "frames": 90 }`.

**Уникальная механика персонажа** (форма друида, ярость варвара, призыв…): наследник `CharacterBehavior`
с атрибутом `[Behavior("имя")]`. Пример — `Combat/Behaviors/ArcaneRecoveryBehavior.cs`.
Подключается строкой `"behavior": "имя"` в character.json. Доступные хуки: `OnRoundStart`, `OnTick`,
`CanUseMove`, `OnMoveStart`, `OnHitLanded`, `OnDamaged`, `OnKnockdown`.

**Новый источник ввода** (геймпад, ИИ, повтор записи) — реализация `IInputSource`.

## Механики движка

- Фиксированный шаг 60 тиков в секунду, логика не зависит от FPS.
- Буфер ввода 5 кадров, движения стиком до 20 кадров, отмену можно ввести во время хитстопа.
- Хитстоп, отталкивание (у стены отталкивается атакующий), взаимные удары (trade).
- Блок стоя и сидя, низ / середина / оверхед, урон по блоку (блок не убивает).
- Броски, тех броска (защищающийся тоже нажал L+M), нокдауны с неуязвимостью при вставании.
- Комбо-счётчик и скейлинг урона (с 3-го удара −10% за удар, минимум 30%).
- Жонглирование в воздухе, снаряды с лимитом и столкновением друг с другом.
- Раунды до 2 побед, 99 секунд, победа по времени — по доле здоровья.
